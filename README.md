# Devflow Skills

Личные скиллы для разработки: спецификация → технический план → реализация.

| Скилл | Название в интерфейсе | Назначение |
| --- | --- | --- |
| `devflow-make-spec` | Спека — создать | Сформулировать требования и критерии результата |
| `devflow-check-spec` | Спека — проверить | Проверить полноту и согласованность спецификации |
| `devflow-make-plan` | План — создать | Подготовить техническое решение и план реализации |
| `devflow-check-plan` | План — проверить | Проверить реализуемость, полноту и ключевые решения плана |
| `devflow-make-diff` | Дифф — создать | Реализовать согласованный объём и проверить результат |

Все скиллы вызываются явно: через выбор в интерфейсе или `$devflow-...`.
В `agents/openai.yaml` каждого скилла установлено
`policy.allow_implicit_invocation: false`.

`devflow-diff-explain` развивается и устанавливается отдельно.

## Установка

Нужны Bash и стандартные утилиты macOS/Linux. Клонируй репозиторий в постоянный
каталог и из его корня выполни:

```bash
bash scripts/install.sh
```

Установщик создаёт абсолютные симлинки из `$HOME/.agents/skills` на папки
в `skills/`. Повторный запуск сохраняет уже правильные ссылки. Если любое имя
занято обычной папкой, файлом или другой ссылкой, установка останавливается
до создания ссылок. Существующие скиллы автоматически не перезаписываются.

Другой каталог установки можно передать первым аргументом:

```bash
bash scripts/install.sh /absolute/path/to/agent/skills
```

Если новые скиллы не появились в Codex, перезапусти приложение.

## Разработка

Редактируй файлы в `skills/`: установленные симлинки ведут прямо на них.
Коммить изменения вместе с соответствующими настройками `agents/openai.yaml`.
После `git pull` обновления доступны через те же ссылки; после добавления нового
скилла повторно запусти установщик.

Каждый скилл хранится в собственной папке с `SKILL.md` и `agents/openai.yaml`.
Для новых скиллов сохраняй префикс `devflow-`, русское название для интерфейса
и только явный вызов.

Каталог репозитория должен оставаться на месте, пока используются симлинки.
При переносе удали только прежние ссылки на этот репозиторий и запусти установщик
из нового расположения. Удаление ссылки не удаляет файлы скилла в репозитории.
